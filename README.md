# ELECTROVA - Premium Electronics E-Commerce Platform

A brand-new, production-ready Electronics Shopping Web Application built from scratch with a Myntra-inspired shopping experience.

---

## ⚡ Highlights & Key Features

- **Brand-New Architecture**: Custom-built with React 18, TypeScript, Tailwind CSS, Lucide icons, Vite, and Supabase.
- **Strict Exclusion**: Strictly **no mobile phones or smartphones** across the entire store.
- **20 Specialized Categories**:
  1. Laptops
  2. Tablets
  3. Smart Watches
  4. Headphones
  5. Earbuds
  6. Bluetooth Speakers
  7. Smart TVs
  8. Digital Cameras
  9. Gaming Consoles
  10. Gaming Accessories
  11. Keyboards
  12. Computer Mouse
  13. Monitors
  14. Printers
  15. Power Banks
  16. Chargers and Cables
  17. Projectors
  18. Home Appliances
  19. Networking Devices
  20. Computer Accessories
- **Over 60 Unique Products**: 62 flagship electronics with high-res galleries, detailed technical specs, color/storage variants, warranties, and stock states.
- **Full-Screen Product Details Page**:
  - Clicking any product opens that product on an individual full-screen page (no small popup or modal).
  - Prominent **BACK TO PRODUCTS** button that restores the customer's exact previous scroll position.
- **Product Review System**:
  - Independent review section for every product.
  - Interactive 1–5 star rating selection, title, and detailed feedback.
  - Verified customer badge and instant recalculation of product ratings and review count.
  - Only authenticated customers can write and submit reviews.
- **Horizontal Review Scrolling**:
  - Reviews scroll horizontally from left to right in smooth individual cards with navigation arrows.
  - Newly submitted reviews appear immediately in the horizontal reel.
- **Continuous Vertical Scrolling After Reviews**:
  - After reviews, customers can continue scrolling down naturally through 7 continuous sections:
    1. Related Electronics
    2. Similar Products
    3. You May Also Like
    4. Frequently Bought Together
    5. Recently Viewed Products
    6. Trending Electronics
    7. More Product Collections
- **Customer Authentication & Account**:
  - Sign Up (Full Name, Email, Mobile, Password, Confirm Password).
  - Sign In (Email, Password, Remember Me, Forgot Password).
  - Profile Menu with Customer Profile, My Orders, My Wishlist, My Cart, My Reviews, Account Settings, and Log Out.
- **Cart, Wishlist & Checkout**:
  - Quantity controls, coupons (`VIPFEST` and `ELECTROVA500`), shipping address, multi-payment options, and celebratory confetti upon order placement.
- **Database Integration**:
  - Supabase client configured with full database schema in `supabase-schema.sql` including Row Level Security (RLS) policies.

## 🚀 Running the Project

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```
